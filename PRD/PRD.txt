SatQuery AI — Product Requirements Document

Project: SatQuery AI
SIH Problem Statement: 26167
Version: 1.0
Type: Multimodal Remote-Sensing Vision-Language Agent
Primary Goal: Enable users to analyze satellite imagery using natural-language questions and receive answers backed by visual/geospatial evidence.

1. Product Overview
1.1 Product Name

SatQuery AI

1.2 One-line description

SatQuery AI is an agentic multimodal AI system that allows users to ask natural-language questions about satellite imagery and receive explainable answers supported by visual, temporal, optical, SAR, and geospatial evidence.

2. Problem Statement

Traditional satellite-image analysis requires users to understand:

GIS software
Remote sensing
Image bands
Raster processing
Change detection
SAR analysis
Machine-learning tools

This creates a barrier for non-expert users.

For example, a user shouldn't need to manually operate several tools to answer:

"What changed in this region between 2022 and 2026?"

or:

"Where are the newly constructed buildings?"

or:

"Does the SAR imagery support the conclusion that this area is urban?"

SatQuery AI should convert these questions into appropriate analysis workflows automatically.

11.4 Agent safety

The agent must not have unrestricted access to the operating system.

It should only be allowed to call registered tools.

For example:

ALLOWED_TOOLS = {
    "run_vqa",
    "detect_change",
    "analyze_sar",
    "analyze_optical"
}

The agent outputs a structured plan rather than arbitrary executable code.

Example:

{
  "task": "change_analysis",
  "steps": [
    "register_images",
    "detect_change",
    "generate_change_summary"
  ]
}

The backend validates this plan before execution.

17. What makes SatQuery different?

A simple system:

Image → VLM → Answer

is not enough for your goal.

SatQuery should become:

Image(s)
   ↓
Understand question
   ↓
Plan analysis
   ↓
Select specialist models
   ↓
Perform geospatial analysis
   ↓
Cross-check evidence
   ↓
Generate visual evidence
   ↓
Explain answer

The key concept is:

Natural language → autonomous multimodal remote-sensing workflow → evidence-backed answer.
